This episode follows the crew through a high-stakes run in *Signals in the Static*, where every choice can shift trust, danger, and momentum.

## Gameplay Synopsis

The other is uglier, older, swollen with oxidation that has bled into the concrete like rust-tea. “Mixed hardware,” Alex murmurs. “One original, one replaced.” He tilts the lantern so the stenciling catches light.
