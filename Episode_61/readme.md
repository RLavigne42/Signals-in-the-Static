# Episode 61 Synopsis

This episode follows the crew through a high-stakes run in *Signals in the Static*, where every choice can shift trust, danger, and momentum.

## Gameplay Synopsis

Alex takes the lie to its logical conclusion—makes it sound like the bunker is already doing what it was built to do: punish the careless. “…THREE. TWO. ONE. ZERO.” His voice hits the corridor like a gavel. “DROP WEAPONS. LIE PRONE. DECON IN PROGRESS.” For a breath, the Analog Order actually wavers. The lantern zealot’s arm dips. The cudgel zealot’s boots shift as if the floor has turned slick. Even the tall one with the black-sun stitching hesitates—doctrine colliding with the old-world fear of *systems you don’t understand*. Then the tall one snarls, loud enough to drown doubt. “NO. There is no purge. There is only sin.” He lunges forward—cudgel raised—not at the door, but toward the shadow where Nolan shouldn’t exist.
