## Gameplay Synopsis

The paper drinks the graphite. Hidden pressure-lines rise like bruises under skin: a rotated grid, a second set of waypoints, and—near the lower fold—a repeated three-letter designation that looks less like a name and more like a filing code. The half-smeared stamp becomes clearer in pieces: not enough for a full seal, but enough to scream *custody chain*. This wasn’t found. It was *handled*. Mila watches the emerging geometry, jaw tight.
